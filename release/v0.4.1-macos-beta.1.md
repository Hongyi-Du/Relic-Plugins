**Relic for macOS Apple silicon: the Relic App and Claude Code/Codex plugin.**

This first macOS prerelease uses the tested **v0.4.1-beta.1** baseline and ships plugin
**0.15.1-macos-beta.1**. The plugin id remains `relic@relic-bridge`. The newer Windows
[v0.6.0-beta.1](https://github.com/Hongyi-Du/Relic-Plugins/releases/tag/v0.6.0-beta.1)
release remains separate; its v0.5/v0.6 features are not included in this Mac build.

- Native **Apple silicon / arm64** only; Python **3.11+**, Node.js **22+** with npm, and
  a signed-in Claude Code and/or Codex installation are required.
- Finder launcher, runtime discovery, macOS shortcuts and file handling, locked ACP
  adapters, and authenticated App start/status/restart/stop.
- Real Claude writer and Codex reviewer members completed tasks, exchanged messages
  and revised a shared document. Local Python 3.11 and 3.13 suites each passed 406 tests
  with two Windows-only skips. The ZIP installation and server lifecycle were checked
  in an isolated directory.
- This is an **unsigned source installer**, not a bundled Python/Node runtime or a
  signed/notarized standalone app. Intel Macs and Rosetta runtimes are outside scope.
  Desktop automatic delivery remains conditional on local host capability checks;
  full browser interaction and sleep/wake coverage remain incomplete.

Download `relic-macos-v0.4.1-macos-beta.1.zip` (or the equivalent `.tar.gz`), compare
it with `SHA256SUMS.txt`, and extract to a permanent folder. In Terminal, from that folder:

```sh
bash install.command --host none --open
```

The installer creates `~/Applications/Relic.app`. Keep the extracted folder, and open
the launcher on later runs. In **Settings → Harness connections**, install the ACP
adapters, then add members with **Run in the App**. To load the plugin in independent
CLI sessions, use `--host claude`, `--host codex` or `--host both`; restart those hosts
and review their plugin hooks. Relic uses your existing host accounts and does not
include model access.

Before replacing an existing Mac installation, stop its server and back up its
`~/.relic` (or selected `RELIC_HOME`) data directory. Install from the new permanent
folder; the managed Finder launcher is updated and organization data is retained.

**Relic 首个 macOS Apple silicon 测试版：Relic App 与 Claude Code/Codex 插件。**

本版基于已验证的 **v0.4.1-beta.1**，插件版本为 **0.15.1-macos-beta.1**。
Windows v0.6.0-beta.1 独立保留，本版不包含 v0.5/v0.6 新增功能。

仅支持 **Apple silicon / arm64**，需要原生 Python **3.11+**、Node.js **22+**（含 npm）
和已登录的 Claude Code 或 Codex。提供 Finder 启动器、运行环境检测、macOS 文件处理与
快捷键、锁定版本的 ACP 适配器，以及服务状态、重启和停止功能。

真实 Claude/Codex 成员已完成任务、消息往返和共享文档修订。Python 3.11/3.13
各通过 406 项测试、跳过两项 Windows 专用测试；ZIP 解压安装与服务生命周期检查通过。
属于**未签名的源码安装包**，不捆绑 Python/Node，不支持 Intel/Rosetta；桌面自动投递
须通过本机宿主能力检查，完整浏览器交互与休眠唤醒测试仍未完成。

下载并校验 ZIP 或 tar.gz，解压到长期保留的目录，在 Terminal 中进入该目录，运行上面的
安装命令。以后从 `~/Applications/Relic.app` 打开。在「设置 → 宿主连接」安装 ACP
适配器，再选择「在 App 中运行」添加成员。独立 CLI 会话需要插件时，可用 `--host claude`、
`--host codex` 或 `--host both` 安装，再重启宿主并检查 hooks。升级前停止旧服务并备份数据目录。
