# macOS 原生 Relic App：Amendment 6 窗口适配

macOS 原先使用固定 SwiftUI `.defaultSize(1440, 900)`，缺少屏幕可用区域适配和显式
窗口框架保存/恢复。现由 `ApplicationWindowPlacement` 按 AppKit 点数处理：首次窗口
为 `min(1440×900 pt, visibleFrame.size × 0.85)`，在当前显示器可用区域居中；使用
`setFrameAutosaveName("Relic.MainWindow")` 保存并恢复窗口。正常最小尺寸为 960×640 pt，
小屏幕时降到不超过默认窗口，避免最小尺寸把内容推到菜单栏或 Dock 后方。

保存的窗口可大于默认值；恢复时将尺寸和位置限制在相交屏幕的可用区域，完全离屏则回到
当前屏幕的默认窗口。显示器移除/可用区域变化会校正越界；切换 backing scale 时只更新
尺寸约束，不重新设置窗口点数框架。新窗口不自动进入全屏。

内容按真实窗口宽高重新排版。右栏沿用 1180 pt 浮层断点，首次窄窗默认关闭右栏且不覆盖
宽窗偏好；820 pt 以下侧栏为 236 pt，900 pt 以下隐藏顶栏居中标题，均对应网页断点。
未对根视图使用缩放变换。11 项新增测试覆盖缩放换算、默认值、小屏幕、第二显示器、
位置恢复/钳制、实际 AppKit 窗口恢复及窄窗偏好。

CI 继续生成两种尺寸、明暗主题的真实整窗图，另外记录实际启动框架、屏幕可用区域、
最小尺寸和浮层状态；截图窗口使用独立临时保存名。最终交付目录为
`S:\Codex\Outputs\Relic-native-visual\window-<commit>\`，实际测试结果和提交见本轮交付报告。

## 真 Mac 验收与交付条件

最低系统：**macOS 14+、Apple silicon**。CI 产物为 **unsigned / 未 notarize** 的 `.app` ZIP。
包内含同源 Python 引擎源码，不捆绑解释器；运行需要 **Python 3.11+**。
使用 ACP 适配器时还需要 **Node.js 22+** 和已安装/登录的对应提供方工具；
可用能力与缺失原因在 Settings/成员表单显示。实际版本号以共享包元数据为准。

本人或 HaochenGu 可在 Mac 上按以下顺序验收：

1. 从 Finder 启动，确认 Dock 图标、菜单栏、三栏窗口；关闭窗口后重开，再用 Quit 退出。
   分别验证自启引擎随退出清理，以及借用已有引擎时原引擎继续运行。
2. 对照参考检查三栏布局、动作顺序、缩放/分栏记忆、浅色/深色/字体、简体中文与英语；
   用 VoiceOver/键盘检查焦点、Tab、快捷键、中文输入法、@ 补全、选区引用与线程发送。
3. 新建组织和三种成员、配置秘书/层级、权限和审批、强/弱协议、Copies、组织图；
   使用真实提供方测试会话打开/绑定/新建/解绑/手动转发和实时工具更新。
4. 检查 Workspace、真实文件/图片/Markdown、路径行号、系统默认 App 打开，
   白话/摘要、任务报告/证据、文档修订和轨迹分页。
5. 在显式点击后测试麦克风/语音许可、拒绝与恢复、中文/英语识别、选区和临时结果；
   测试通知许可、后台通知点击后的正确会话导航，以及服务端重启后的重连。
