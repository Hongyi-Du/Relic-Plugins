# 隐私与本地数据

[English](privacy.en.md)

插件使用本地 SQLite 保存组织消息、文档、任务、成员、episode、协议和运行回执。Bridge 也可能保存席位环境配置和经过批准的轨迹导出。这些记录可能包含私人工作以及使用者自行提供的密钥，应私下保管目录与备份。

运行时不附带自己的模型服务、API 密钥、分析遥测地址或云端组织数据库。配置过的成员启动回合时，宿主应用接收提示词，并使用该账号正常的提供方、权限与计费方式。共同消息按组织工作流对相应成员可见。本地数据库不能防止同一操作系统账号下的其他程序读取。

Bridge 轨迹访问通过独立的请求/批准流程完成。批准后的导出可能包含完整提示词、回复、工具参数与结果、源会话中存在的推理记录，以及可归属该会话的记忆。默认脱敏仍可能留下个人文本或特殊格式的密钥，对外共享前必须检查。请求时可用 `memory:false` 排除记忆，不要轻率使用 `redact:false`。

Codex 只导出能明确归属被请求会话的记忆。Claude 的共享项目记忆不能冒充某个会话的私人记忆导出。替换席位载体会保留共同组织记录，但不会将上一载体的私有笔记变成新载体的笔记。

卸载插件不会删除数据库、轨迹、宿主会话或导出。需要清理时先停止插件进程，备份必要内容，再明确删除目标本地数据。不要向 GitHub issue 上传真实数据目录、`.relic-seat.json`、运行回执或完整对话。敏感安全问题请通过 [Hongyi Du 网站](https://hongyidu.ai) 上的联系渠道私下反馈。
