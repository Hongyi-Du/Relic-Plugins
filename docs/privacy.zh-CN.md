# 隐私与本地数据

[English](privacy.en.md)

Relic 使用本地 SQLite（`~/.relic/relic.sqlite3`）保存组织消息、文档、任务、成员、episode、协议和运行回执，也可能保存席位环境配置和经过批准的轨迹导出。这些记录可能包含私人工作以及使用者自行提供的密钥，应私下保管目录与备份。Relic 保存的一切都在 `~/.relic`（设置了 `RELIC_HOME` 时在该目录）：数据库、App 的文件在 `app/`、ACP 适配器在 `acp/`、日志在 `runs/`、在 App 里添加的成员的默认文件夹在 `workspaces/`、轨迹导出在 `trajectories/`。

运行时不附带自己的模型服务、API 密钥、分析遥测地址或云端组织数据库。插件的 MCP 服务和 hooks 不调用任何模型。成员启动回合时，宿主应用接收提示词，并使用该账号正常的提供方、权限与计费方式；在 Relic App 里运行的成员就是你自己的 Claude Code 或 Codex 会话，同样如此。共同消息按组织工作流对相应成员可见。本地数据库不能防止同一操作系统账号下的其他程序读取。

轨迹访问通过独立的请求/批准流程完成。批准后的导出可能包含完整提示词、回复、工具参数与结果、源会话中存在的推理记录，以及可归属该会话的记忆。默认脱敏仍可能留下个人文本或特殊格式的密钥，对外共享前必须检查。请求时可用 `memory:false` 排除记忆，不要轻率使用 `redact:false`。

Codex 只导出能明确归属被请求会话的记忆。Claude 的共享项目记忆不能冒充某个会话的私人记忆导出。替换席位载体会保留共同组织记录，但不会将上一载体的私有笔记变成新载体的笔记。

Relic App 只在本机 127.0.0.1 上提供服务：请求必须指向本机地址，写操作需要只有 App 页面能读到的令牌。它把你的名字、头像、偏好以及「人话」「解读」的结果存在 `~/.relic/app/`；不是作为装好的应用、而是在 Edge 或 Chrome 窗口里打开时，该窗口的浏览器配置存在 `~/.relic/app-window`。「人话」「解读」和成员自动命名会把相关的组织消息和成员职责发给你已登录的 Claude Code（`claude -p`，不保存会话；「人话」「解读」用 Sonnet，命名用 Haiku），按你的 Claude 账号正常处理和计费；不想这样就别在群聊里打开这两项，并在设置里关掉自动命名。只有你在「设置 → Harness 连接」里安装 ACP 适配器时，App 才从 npm 下载它们。文件预览只读取成员的工作目录、成员改过的文件和 Relic 数据目录。语音输入使用 Microsoft Edge 自带的在线语音识别。

卸载插件不会删除数据库、轨迹、宿主会话或导出。需要清理时先停止 Relic 的进程（包括 App 的服务），备份必要内容，再明确删除目标本地数据。不要向 GitHub issue 上传真实数据目录、`.relic-seat.json`、运行回执或完整对话。敏感安全问题请通过 [Hongyi Du 网站](https://hongyidu.ai) 上的联系渠道私下反馈。
